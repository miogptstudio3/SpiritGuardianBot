# 👻 راهنمای محافظ ارواح

ربات بازی تلگرامی با موضوع ارواح، جن‌ها، مأموریت‌ها و پاک‌سازی موجودات فانتزی.

## اجرا
1. Python 3.11 یا بالاتر نصب کنید.
2. `pip install -r requirements.txt`
3. فایل `.env.example` را به `.env` تغییر نام دهید.
4. توکن BotFather را در `BOT_TOKEN` قرار دهید.
5. شناسه عددی ادمین را در `ADMIN_IDS` قرار دهید.
6. اجرا: `python bot.py`

دیتابیس SQLite به صورت خودکار ساخته می‌شود.

## نگهداری دائمی اطلاعات بازیکنان روی Render

SQLite اطلاعات را در `spirits.db` نگه می‌دارد. برای اینکه با Deploy مجدد Render پیشرفت بازیکنان پاک نشود، باید یک Persistent Disk به Web Service وصل کنی و Mount Path آن را `/var/data` بگذاری. کد به‌صورت خودکار در `/var/data/spirits.db` ذخیره می‌کند.

اگر Persistent Disk نداری، فایل‌سیستم محلی Render می‌تواند با Deploy/Restart از بین برود و SQLite برای نگهداری دائمی مناسب نیست.

می‌توانی در Environment Variables نیز مقدار زیر را صریحاً تعیین کنی:
`DB_PATH=/var/data/spirits.db`

### اجرای Web App
`python web_app.py`

روی Render می‌توانی یک Web Service جدا برای Web App بسازی و Start Command را این بگذاری:
`python web_app.py`

Environment Variables:
- `BOT_TOKEN` همان توکن ربات
- `DB_PATH=/var/data/spirits.db`

Persistent Disk را روی `/var/data` قرار بده تا وب‌اپ و ربات از همان دیتابیس دائمی استفاده کنند.

### اتصال Web App به ربات
در BotFather برای Web App یک URL بساز و URL سرویس Render را به آن بده. Web App فقط وقتی درخواست API را می‌پذیرد که Telegram `initData` معتبر ارسال کرده باشد؛ بنابراین کاربر نمی‌تواند صرفاً با تغییر یک `user_id` وارد پنل شخص دیگری شود.
