# 👻 راهنمای محافظ ارواح

ربات بازی تلگرامی با موضوع ارواح، جن‌ها، مأموریت‌ها و پاک‌سازی موجودات فانتزی.

## اجرا
1. Python 3.11 یا بالاتر نصب کنید.
2. `pip install -r requirements.txt`
3. فایل `.env.example` را به `.env` تغییر نام دهید.
4. توکن BotFather را در `BOT_TOKEN` قرار دهید.
5. شناسه عددی ادمین را در `ADMIN_IDS` قرار دهید.
6. اجرا: `python bot.py`

دیتابیس SQLite به صورت خودکار ساخته می‌شود.
